# Image checklist

**0 of 99 slots have a photo.**

Every place on the site that can show a real photo. Save a file with the name in the **File** column inside `web/public/images/`; any of `.jpg`, `.jpeg`, `.png`, `.webp` or `.avif` works (and `.svg` for the logo). How-to: [09-adding-images.md](09-adding-images.md).

Regenerate this list with `npm run images:list` (run inside the `web` folder).
