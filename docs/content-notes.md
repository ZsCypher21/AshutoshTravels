# Content notes: corrections, flags & placeholders

The rewrite uses **only TravelWeb.pdf** as its source. Wording was modernised throughout; facts were kept unless they were internally contradictory, garbled, clearly out of date, or a liability. Every such change is listed here so the family can confirm it.

Items flagged in code with `needsVerification` show as red **Verify** badges when running `npm run dev`.
