# Photos go here

Save a photo in this folder with the right name and the website shows it in place of the placeholder art. No code changes needed.

Examples:

- `pages/home.jpg`: home page header
- `destinations/pokhara.jpg`: Pokhara card and page header
- `team/ceo.jpg`: CEO portrait on the About page
- `logo.svg` (or `logo.png`): the agency logo

The full list of file names is in `docs/image-checklist.md` (run `npm run images:list` to refresh it), and the step-by-step guide is `docs/09-adding-images.md`.
